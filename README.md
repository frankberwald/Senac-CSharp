# 📚 Senac-CSharp

Repositório dedicado aos estudos de **C#** no curso do **Senac**. Aqui você encontrará diversos exemplos, exercícios e projetos desenvolvidos ao longo do aprendizado da linguagem, cobrindo desde os conceitos básicos até tópicos mais avançados.

## 🧠 Objetivo

Este repositório tem como finalidade:

- Consolidar os conhecimentos adquiridos durante as aulas;
- Servir como material de apoio para revisões e estudos;
- Compartilhar soluções de exercícios e boas práticas com a comunidade.

## 🚀 Conteúdo

A estrutura do projeto está organizada por temas ou semanas, e cada pasta contém os arquivos `.cs` correspondentes aos exercícios ou projetos desenvolvidos. Alguns tópicos abordados incluem:

- Sintaxe básica do C#
- Estruturas de decisão e repetição
- Vetores e matrizes
- Programação orientada a objetos (POO)
- Manipulação de arquivos
- Interfaces gráficas com WinForms
- Acesso a banco de dados com ADO.NET

> ⚠️ Algumas pastas podem ainda estar em construção ou conter exemplos inacabados — este é um repositório de estudo em constante evolução.

## 🛠️ Tecnologias Utilizadas

- [C#](https://docs.microsoft.com/pt-br/dotnet/csharp/)
- [.NET Framework / .NET Core](https://dotnet.microsoft.com/)
- Visual Studio / Visual Studio Code
- WinForms

## 📌 Requisitos

Para rodar os projetos localmente, é recomendado ter:

- .NET SDK instalado
- Visual Studio ou Visual Studio Code configurado para C#
- (Opcional) SQL Server Express para projetos com banco de dados
